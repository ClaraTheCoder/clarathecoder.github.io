    WRITING NOTES

    Intro — worth covering:
    • What "primitives" are: raw, context-free values — no semantics, no
      theming. The bottom of the three tiers: primitives → semantics → components.
    • Why OKLCH: perceptually-even lightness so ramps step evenly; wide-gamut
      (P3) with the browser falling back to sRGB automatically.
    • Where the seven accents come from (the site's background "swirl"), and that
      they're named after Kanto towns — vermilion, saffron, viridian, celadon,
      cerulean, lavender, fuchsia; the neutral is a cool-tinted grey (hue 275)
      chosen to sit with the cool accents.
    • How to consume: import `@clara/tokens/primitives.css`, reference
      `var(--color-<hue>-<step>)`. Components shouldn't use these directly —
      the semantic tier will alias them.

    Links:
